The changes are surgical—only a few dozen lines—yet give you the full theoretical behaviour described in your note (finite memory, adaptive λ, bucket control still intact).

2 Adaptive-λ helper
Create hkf_lambda.py (shared by all filters):

python
Copy
import numpy as np

VOL_THRESHOLD = 0.002   # 0.2 % 1-sec volatility ≈ “elevated”

def adaptive_lambda(volatility: float,
                    base_lambda: float = 0.99,
                    lam_min: float = 0.95,
                    lam_max: float = 0.995) -> float:
    """
    Shrink λ when 1-second realised volatility spikes.
    `volatility` is abs(dPrice)/Price.
    """
    vol_norm = min(volatility / VOL_THRESHOLD, 2.0)      # 0–2
    return lam_max - (lam_max - lam_min) * (vol_norm / 2.0)

4 Numerical safeguards
Add after the covariance update (file end of loop, just after kf.update(...)):

python
Copy
# Joseph stabilisation (optional but recommended)
I = np.eye(kf.dim_x)
kf.P = (I - kf.K @ kf.H) @ kf.P @ (I - kf.K @ kf.H).T + kf.K @ kf.R @ kf.K.T
This keeps P positive-definite if λ is aggressive (e.g. 0.95).

7 What changed conceptually?
Component	Before	After (λ-KF)
Memory horizon	Infinite (all past equally)	Exponential: weight = λᵏ
hkf_cfg knobs	bucket_weight only	bucket_weight, lambda_fixed, lambda_adaptive
Prediction covariance	P ← F P Fᵀ + Q	P ← (1/λ) F P Fᵀ + Q
Control vector	Same bucket-driven u_t	Unchanged (applied before covariance add)
Numerical stabilisation	None	Optional Joseph form after update

With λ = 0.99, the effective memory is ≈ 100 seconds; with λ = 0.97 only ≈ 33 seconds.
